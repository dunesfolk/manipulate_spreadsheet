This repository contains script to help daily spreadsheet tasks.
# merge_sheet_to_book.bas
フォルダー内のすべての .xls および .xlsx ファイルの 第1シート を、現在のブックにそれぞれ 個別のシートとして結合します。Excel 2019 以降で動作。

# wiztree_diff.py
WiztreeのCSVを比較して差分を出す。

# ndc-converter.html
受発注・在庫管理業務のNDC2システム(NetDataCenter)の受注画面では先方店舗コードしか表示されず、自社顧客コードが表示されません。
このスクリプトは先方店舗コードを自社店舗コードに変換し、自社店舗コード、自社商品コード、納品日、数量からなるCSVファイルを作成します。
また、Office365やGoogle Spreadsheetで開けるようにエンコードをShift-JISからUTF-8 BOMありへ変更します。
